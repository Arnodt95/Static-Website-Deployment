# My Childhood (Static Website)

A simple single-page HTML site about childhood hobbies and toys.

## Preview
Open `index.html` in any web browser.

## Files
- `index.html` — main page
- `running.png` — image for “Running”
- `jigsaw.png` — image for “Jigsaw Puzzles”
- `ball.png` — image for “Ball”
- `car.png` — image for “Toy Cars”

## Notes
- Uses a “Back to top” anchor link (`href="#the-heading"`).
- No CSS/JS included — pure HTML.
